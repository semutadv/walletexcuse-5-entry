One excuse, written for the make.fun bounty "The 3 AM Excuse": a
hardware wallet declines to sign. Nothing legitimate, it points out,
has ever needed a signature at 3 a.m. — and unlike its owner at that
hour, it has read the owner's history of decisions and remembers all
of them.

## Running it

`node main.ts` clears the output directory's contents and writes the
line to `/output/entry.txt` as plain UTF-8 text.
